## FAQ

### Is OmniPatch safe to use on my computer?

Yes, OmniPatch is a clean utility that modifies application files locally. It does not contain tool, connect to external servers for malicious purposes, or compromise your system security.

### Which specific applications does OmniPatch support?

It currently supports ChatGPT, Claude, Perplexity, Microsoft Copilot, Cursor, GitHub Copilot, Devin, and JetBrains AI Assistant, with plans to add more popular AI tools in future updates.

### How often are new versions or patches released?

Updates are released on a bi-weekly basis or as soon as a supported application receives an update that requires a patch refresh. All updates are documented in the repository.

### Do I need to disable my anticomponent software?

Some anticomponent programs may flag patching tools as potentially unwanted. You may need to create an exclusion for OmniPatch, as it alters application binaries, which is expected behavior for a patcher.

### Will this work with my existing account and settings?

Yes. OmniPatch operates at the application level and does not alter your user account data, conversation history, or personal settings within the AI tools.

### Is there a trial or free version available?

OmniPatch is distributed as a complete, free utility. All features and supported applications are available without any payment or subscription requirements.

### What should I do if a patch doesn't work for a specific app?

First, ensure you have the latest version of OmniPatch. If the issue persists, open a detailed issue report on the GitHub repository with your application version and operating system details.

### Can I use OmniPatch on macOS or Linux?

No, OmniPatch is currently designed and compiled exclusively for the Windows operating system (Windows 10 and later).
